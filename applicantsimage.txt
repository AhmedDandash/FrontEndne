## 1. إضافة عامل جديد (Create Worker)
عند إنشاء عامل جديد، يمكنك الآن إرسال قائمة بروابط الصور (URLs) في حقل جديد يسمى `attachments`.

**Endpoint:** `POST /api/Worker`

**Payload Example:**
```json
{
  "fullNameAr": "أحمد محمد",
  "nationalityId": "...",
  "jobId": "...",
  "uploadImage": "https://example.com/profile.jpg", // الصورة الشخصية الأساسية
  "attachments": [
    "https://example.com/passport_copy.jpg",
    "https://example.com/visa_copy.jpg",
    "https://example.com/medical_report.jpg"
  ],
  "isActive": true
  // ... باقي الحقول
}
```

---

## 2. تعديل بيانات العامل (Update Worker)
عند التعديل، يمكنك إرسال القائمة الجديدة للصور. النظام الحالي سيقوم باستبدال الصور القديمة بالصور الجديدة المرسلة في المصفوفة.

**Endpoint:** `PUT /api/Worker/{id}`

**Payload Example:**
```json
{
  "attachments": [
    "https://example.com/new_image1.jpg",
    "https://example.com/new_image2.jpg"
  ]
}
```
*ملاحظة: إذا أرسلت مصفوفة فارغة `[]` سيتم حذف جميع المرفقات. إذا لم ترسل الحقل نهائياً لن يتم تغيير الصور.*

---

## 3. جلب بيانات العامل (Get Worker By ID)
عند طلب بيانات العامل، ستجد حقل `attachments` يحتوي على جميع الصور المرتبطة به.

**Endpoint:** `GET /api/Worker/{id}`

**Response Example:**
```json
{
  "id": "...",
  "fullNameAr": "أحمد محمد",
  "uploadImage": "https://example.com/profile.jpg",
  "attachments": [
    "https://example.com/passport_copy.jpg",
    "https://example.com/visa_copy.jpg"
  ]
}
```

---

## ملاحظات هامة للفرونت إند:
1. **الصورة الأساسية (`uploadImage`)**: ما زالت موجودة وتستخدم كصورة البروفايل الرئيسية للعامل.
2. **المرفقات الإضافية (`attachments`)**: هي مصفوفة نصوص (Array of Strings) تحتوي على روابط الصور الإضافية.
