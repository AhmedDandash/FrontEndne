2. Attendance Management
Base URL: /api/HR/Attendance | Authentication: JWT Bearer Token required for all endpoints.
POST /api/HR/Attendance/CheckIn
Employee Check-In
Records the check-in time for the currently authenticated employee. The employee is identified automatically
from the JWT token.
Response
200 OK — Check-in recorded. Returns error if already checked in today.
Note: No request body required. Employee ID is resolved from the authenticated user's token.
POST /api/HR/Attendance/CheckOut
Employee Check-Out
Records the check-out time and calculates late minutes and overtime minutes based on shift schedule.
Response
200 OK — Check-out recorded with calculated durations. Returns error if no check-in found.
Note: System automatically calculates LateMinutes and OvertimeMinutes used in payroll generation.

5. Payroll Management
Base URL: /api/HR/Payroll | Payroll is calculated per month/year. Formula: NetSalary = BaseSalary + Overtime 
LateDeduction - AbsenceDeduction - LeaveDeduction + Bonus - AdditionalDeduction.

Generates payroll for all active employees for the specified month and year. Calculates salary, deductions,

OvertimeAmount = (TotalOvertimeMinutes / 60) * OvertimeHourRate - AbsenceDeduction = AbsentDays * (BasicSalary /

Appendix: End-to-End Workflow Summary
New Employee Onboarding
1 POST /api/HR/Employee — Create employee (auto-creates user account + leave balances)
2 GET /api/HR/Employee/{id} — Verify employee data
3 PUT /api/HR/Employee/{id}/reset-password — Send password to employee
Daily Attendance
1 POST /api/HR/Attendance/CheckIn — Employee checks in at start of shift
2 POST /api/HR/Attendance/CheckOut — Employee checks out (late/overtime auto-calculated)
3 POST /api/HR/Attendance/Filter — HR views attendance records by date/employee
Leave Request Lifecycle
1 GET /api/HR/Leave/balance/{leaveTypeId} — Employee checks available balance
2 POST /api/HR/Leave — Employee submits leave request
3 GET /api/HR/Leave — HR reviews all pending requests
4 PUT /api/HR/Leave/{id}/approve OR /reject — HR takes action
5 PUT /api/HR/Leave/{id}/cancel — Employee or HR cancels if needed
Monthly Payroll Processing
1 POST /api/HR/Payroll/generate — Generate payroll (uses attendance + leave data)
2 GET /api/HR/Payroll?month=X&year;=Y — Review payroll details
3 GET /api/HR/Payroll/export?month=X&year;=Y — Export Excel report
4 PUT /api/HR/Payroll/close/{id} — Lock the payroll run
All endpoints return ApiResponse<T> with fields: StatusCode, Data, Message. Authenticated endpoints require Authorization:
Bearer <token> header.
