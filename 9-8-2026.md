# Day 9/8/2026 — Search Filters (Frontend Wiring Guide)

> **Audience:** Front-end team  
> **Date:** 2026-08-09  
> **Topic:** Wire UI search filters for **متابعة العقود** and **المقيمين بالشهر**  
> **Breaking changes:** None — all params are optional. Existing filters still work.

---

## Summary

| Screen (UI) | Endpoint | Query DTO |
|-------------|----------|-----------|
| متابعة العقود / عقود التوسط | `GET api/Mediation/MediationContract` | `FilterMediationContractDto` |
| Export عقود التوسط | `GET api/Mediation/MediationContract/export` | Same DTO |
| متابعة العقود (dashboard) | `GET api/Mediation/MediationFollowUp/dashboard` | Same DTO |
| المقيمين بالشهر | `GET api/EmploymentOperatingContract` | `EmploymentOperatingContractQuery` |

**Rules**

- Omit empty values (`null` / don’t send) — empty string is ignored for most string filters after trim
- Filtering runs **before** pagination
- Export uses the **same** filter logic as the list
- Date ranges: `From` = `>=`, `To` = `<=` (send ISO dates)
- ASP.NET binds query params **case-insensitively**

**Pagination**

| Screen | Page param | Size param |
|--------|------------|------------|
| Mediation / Follow-Up | `page` | `pageSize` |
| المقيمين بالشهر | `pageNumber` | `pageSize` |

### 1.3 New params today (2026-08-09)

| Query param | Type | Behavior |
|-------------|------|----------|
| `customerName` | `string?` | Contains on `Customer.ArabicName` **or** `Customer.EnglishName` |
| `customerNameMatch` | `StringMatchMode` | Default `Contains` |
| `workerName` | `string?` | Contains on `Worker.FullNameAr` **or** `Worker.FullNameEn` |
| `workerNameMatch` | `StringMatchMode` | Default `Contains` |
| `invoicePaymentDateFrom` | `DateTime?` | `InvoicePaymentDate >= from` |
| `invoicePaymentDateTo` | `DateTime?` | `InvoicePaymentDate <= to` |

> Note: `paymentDateFrom` / `paymentDateTo` still filter **payment records** (`Payments.PaymentDate`).  
> For the UI field **تاريخ سداد الفاتورة**, use **`invoicePaymentDateFrom` / `invoicePaymentDateTo`**.

## 2. المقيمين بالشهر (Employment Operating Contracts)

Endpoint: `GET api/EmploymentOperatingContract`  
Pagination: **`pageNumber`** + `pageSize`

### 2.1 UI → Query param map

| UI label | Query param | Type | Notes |
|----------|-------------|------|-------|
| رقم العقد | `contractNumber` | `int?` | Exact |
| الإسم عربي | `arabicName` | `string?` | **NEW alias** — customer Arabic **or** worker Arabic name |
| حالة العقد | `contractStatus` | `short?` | See enum below |
| جوال / الهاتف | `phone` | `string?` | **NEW alias** — worker phone **or** customer phones |
| البريد الالكتروني | `customerEmail` | `string?` | Contains |
| رقم الهوية | `identityNumber` | `string?` | Customer identity / national id |
| تاريخ التوقيع | `signatureDateFrom` / `signatureDateTo` | `DateTime?` | **NEW alias** of contract start date (`ContractStartDate`) |
| تاريخ الانشاء | `createdDateFrom` / `createdDateTo` | `DateTime?` | |
| الجنسية | `nationalityId` | `Guid?` | |
| الوظيفة | `jobId` | `Guid?` | |
| تم الانشاء بواسطة | `createdBy` | `string?` | Exact match |
| ينتهى بعد | `expiresAfterDays` | `int?` | End date within N days from today (UTC) |
| النوع | `type` **or** `operationType` | `short?` | `type` is alias of `operationType` |
| تاريخ نهاية العقد (dropdown) | `expirationCondition` | `1\|2\|3` | See enum |
| الحالة المالية | — | — | **NOT SUPPORTED** — no financial-status field — hide/disable |
| حالة العقد (الكل) | `isFinish` | `bool?` | Finished / not finished |
| المسوق | `marketerId` | `Guid?` | |
| حالة اختيار العمالة | `laborSelectionStatus` | `short?` | Alias of `laborManagement` |
| تاريخ نهاية العقد (date) | `contractEndDateFrom` / `contractEndDateTo` | `DateTime?` | |
| رقم جواز السفر | `workerPassportNumber` | `string?` | Contains |

### 2.2 New / alias params today (2026-08-09)

| Query param | Type | Behavior |
|-------------|------|----------|
| `arabicName` | `string?` | Customer `ArabicName` **or** contract `WorkerNameAr` |
| `phone` | `string?` | `WorkerPhone` **or** any customer phone |
| `signatureDateFrom` / `signatureDateTo` | `DateTime?` | Alias of `contractDateFrom` / `contractDateTo` on `ContractStartDate` |
| `type` | `short?` | Alias of `operationType` |

Still valid (more specific) alternatives:

- `customerArabicName`, `workerNameAr`
- `customerPhone`, `workerPhone`
- `contractDateFrom`, `contractDateTo`
- `operationType`

If both specific + alias are sent, **both apply (AND)** — prefer sending **one**.

### 2.3 `expirationCondition`

| Value | Name | Meaning |
|------:|------|---------|
| `1` | NotExpired | `contractEndDate >= today` |
| `2` | Expired | `contractEndDate < today` |
| `3` | ExpiringWithinDays | Within `expiresAfterDays` (default **30** if omitted) |

### 2.4 `contractStatus`

| Value | Name |
|------:|------|
| `1` | Draft |
| `2` | Signed |
| `3` | Executing |
| `4` | Finished |
| `5` | PendingApproval |

### 2.5 Example

```http
GET /api/EmploymentOperatingContract
  ?arabicName=أحمد
  &phone=05
  &signatureDateFrom=2026-01-01
  &signatureDateTo=2026-08-01
  &expirationCondition=3
  &expiresAfterDays=15

  &workerPassportNumber=A12

```

## 4. FE checklist

- [ ] Wire **متابعة العقود**: `customerName`, `workerName`, `invoicePaymentDateFrom/To`
- [ ] Hide **حاله عقد مساند**
- [ ] Wire **المقيمين بالشهر**: `arabicName`, `phone`, `signatureDateFrom/To`, `type`, expiration, labor, passport, etc.
- [ ] Hide **الحالة المالية**
- [ ] Confirm pagination: Mediation → `page`; Operating → `pageNumber`
- [ ] Date pickers send ISO; omit empty params
- [ ] Don’t send conflicting pairs (e.g. both `contractDateFrom` and `signatureDateFrom` with different values)
