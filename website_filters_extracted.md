# Website Search Filters Documentation

This document summarizes the search filters identified across three distinct pages within the recruitment management portal.

---

## Page 1: Mediation Contracts (عقود التوسط)
**Page Purpose:** Used by recruitment agencies to track, filter, and manage domestic worker recruitment contracts and Musaned platform interactions.

### Filters List
* **Contract Number (رقم العقد):** Text input for internal contract ID.
* **Musaned Contract Number (رقم العقد في مساند):** Search by official Musaned platform contract ID.
* **Client Name (اسم العميل):** Search by employer's full name.
* **Mobile Number (الجوال):** Search by customer phone number.
* **Nationality (الجنسية):** Filter by worker nationality.
* **Agents / Agencies (الوكلاء):** Filter by recruitment agency or foreign representative.
* **National ID / Iqama Number (رقم الهوية):** Search by employer ID/Iqama.
* **Designated Worker (عامل معين):** Filter by whether a specific worker was specified or non-specified.
* **External Status (الحالة الخارجية):** Current recruitment/processing status in the origin country.
* **Contract Status (حالة العقد):** Current internal contract operational state (e.g., Active Contracts).
* **Musaned Contract Status (حالة عقد مساند):** Live status synced with the Musaned platform.
* **Manual Contract Status (حالة العقد اليدوي):** Status tracking for offline/manual contract records.
* **Visa Number (رقم التأشيرة):** Filter by issued visa number.
* **Passport Number (رقم جواز السفر):** Filter by worker passport ID.
* **Worker Name (اسم العامل):** Search by worker full name.
* **Worker ID / Number (رقم العامل):** Search by internal worker identification number.
* **Domestic Worker Insurance (تأمين عقود العمالة المنزلية):** Domestic worker insurance coverage status.
* **Visa Status (حالة التأشيرة):** Filter by visa processing stage.

### Advanced Search Filters (بحث متقدم)
* **Incomplete External Status (حالة خارجية لم تتم):** Filter for uncompleted or blocked external agency steps.
* **Invoice Payment Date (تاريخ سداد الفاتورة):** Date selector for invoice settlement.
* **Past External Status (حالة خارجية مرت على العقد):** Filter by historical external status states.
* **Payment Status (حالة الدفع):** Financial payment completion state.
* **Warranty / Guarantee Status (حالات الضمان):** Trial period and warranty status.
* **Created By (تم الانشاء بواسطة):** Filter by the user or system account that created the record.
* **Creation Date (تاريخ الانشاء):** Date selector for contract creation date.
* **Cancellation Date (تاريخ الالغاء):** Date selector for contract cancellation.
* **Arrival Date (تاريخ الوصول):** Date selector for worker arrival date.
* **Visa Date (تاريخ التأشيرة):** Date selector for visa issuance date.
* **Contract Replacement (استبدال العقود):** Filter for substituted worker contracts.
* **Musaned Payment (سداد مساند):** Payment status on the Musaned platform.
* **Marketer / Salesperson (المسوق):** Filter by sales representative or agent.
* **Reference Number (Ref):** Internal tracking or reference code.
* **Workers Added Today (عمالة تم اضافتها اليوم):** Quick filter for daily additions.
* **Religion (الديانة):** Filter worker religion.
* **Prior Experience (سبق له العمل):** Filter whether the worker has previous work experience (Yes/No).
* **Occupation / Job Title (الوظيفة):** Specific job role (e.g., Housemaid, Driver).
* **VIP / Important Client (عميل مهم):** Priority customer flag.
* **Mediation Contract Type (نوع عقد التوسط):** Specific subtype of mediation agreement.

## Page 2: Automatic Follow-Up (المتابعة التلقائية - عقود التوسط)
**Page Purpose:** Used to automatically monitor contract milestones, recruitment timelines, delay threshold flags, and post-arrival workflows.

### Filters List
* **Contract Number (رقم العقد):** Search by internal contract ID.
* **Musaned Contract Number (رقم العقد في مساند):** Search by Musaned platform contract ID.
* **Client Name (اسم العميل):** Search by employer's name.
* **Mobile Number (الجوال):** Search by customer phone number.
* **Nationality (الجنسية):** Filter worker nationality.
* **Agents / Agencies (الوكلاء):** Filter by external agents/agencies.
* **National ID / Iqama Number (رقم الهوية):** Search by employer ID.
* **Designated Worker (عامل معين):** Filter for specified vs. non-specified worker requests.
* **External Status (الحالة الخارجية):** Foreign agency recruitment status.
* **Musaned Contract Status (حالة عقد مساند):** Agreement state on Musaned.
* **Manual Contract Status (حالة العقد اليدوي):** State of offline or manual contract entries.
* **Payment Status (حالة الدفع):** Financial settlement status.
* **Visa Number (رقم التأشيرة):** Search by issued visa reference number.
* **Passport Number (رقم جواز السفر):** Search by worker passport details.
* **Worker Name (اسم العامل):** Search by worker full name.
* **Invoice Payment Date (تاريخ سداد الفاتورة):** Date picker for invoice settlement.
* **Visa Status (حالة التأشيرة):** Dropdown filter for visa processing stage.

### Advanced Search Filters (بحث متقدم)
* **External Status Date (تاريخ الحالة الخارجية):** Date picker for the latest external status update.
* **Warranty / Guarantee Status (حالات الضمان):** Worker trial period warranty conditions.
* **Mediation Contract Type (نوع عقد التوسط):** Subtype classification of the mediation agreement.
* **Created By (تم الانشاء بواسطة):** Account that created the record.
* **Creation Date (تاريخ الانشاء):** Record creation date selector.
* **Arrival Date (تاريخ الوصول):** Worker arrival date filter.
* **Visa Date (تاريخ التأشيرة):** Date picker for visa issuance.
* **Contract Replacement (استبدال العقود):** Filter for replaced worker contracts.
* **Musaned Payment (سداد مساند):** Platform payment status.
* **Reference Number (Ref):** Internal tracking reference.
* **Workers Added Today (عمالة تم اضافتها اليوم):** Quick filter for newly registered workers.
* **Religion (الديانة):** Worker religion filter.
* **Prior Experience (سبق له العمل):** Prior work history filter (Yes/No).
* **Occupation / Job Title (الوظيفة):** Selected job position.
* **Contracts with Arrival Date but Not Arrived in > X Days (عقود لها تاريخ وصول ولم يتم وصولها منذ أكثر من):** Numerical filter to flag overdue arrivals based on days elapsed.
* **Contracts with Signing Date but Not Arrived in > X Days (عقود لها تاريخ توقيع ولم يتم وصولها منذ أكثر من):** Numerical filter to flag long-pending contracts from signature date.
* **Email Address (البريد الالكتروني):** Search by customer email address.
* **Back-out / Cancellation Status (باك أوت):** Dropdown to filter canceled or backed-out agreements.

## Page 3: Rental / Operating Contracts (عقود التشغيل - الإيجار)
**Page Purpose:** Used to manage, query, and monitor worker rental, operational service contracts, and ongoing placement periods.

### Filters List
* **Contract Number (رقم العقد):** Text input for contract ID.
* **Arabic Name (الإسم عربي):** Search by employer or client name in Arabic.
* **Contract Status (حالة العقد):** Filter active/inactive contract states.
* **Mobile / Phone (جوال / الهاتف):** Search by client contact phone number.
* **Email Address (البريد الالكتروني):** Search by client email address.
* **National ID / Iqama Number (رقم الهوية):** Search by client national ID or resident ID.
* **Signing Date (تاريخ التوقيع):** Date selector for contract signature date.
* **Creation Date (تاريخ الانشاء):** Date selector for record creation date.
* **Nationality (الجنسية):** Dropdown filter for worker nationality.
* **Occupation / Job Title (الوظيفة):** Filter by assigned worker job role.
* **Created By (تم الانشاء بواسطة):** Filter by the staff member who logged the record.
* **Expires After (ينتهى بعد):** Filter contracts expiring within a specific number of days.
* **Gender / Type (النوع):** Dropdown filter for gender or service classification.
* **Contract Expiration Condition (تاريخ نهاية العقد):** Filter condition/status regarding contract expiration.
* **Financial Status (الحالة المالية):** Filter by payment and balance state.
* **Contract Status Filter (حالة العقد):** Status dropdown selector (e.g., All).
* **Marketer / Salesperson (المسوق):** Filter by sales representative or agent.
* **Labor Selection Status (حالة اختيار العمالة):** Status of worker selection or assignment.
* **Contract Expiration Date (تاريخ نهاية العقد):** Exact date selector for contract expiration date.
* **Passport Number (رقم جواز السفر):** Search by worker passport number.
